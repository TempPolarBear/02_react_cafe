# Cafe Feedback

Небольшое React-приложение для сбора отзывов о кафе.

## Features

- Оценка по трём категориям: good, neutral и bad
- Подсчёт общего количества отзывов и процента положительных
- Сброс результатов
- Сообщение, пока отзывов нет

## Technologies

- React
- TypeScript
- Vite
- CSS Modules
- modern-normalize

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```
